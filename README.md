
# Microsoft Corporate Financial Statement Analysis (2022–2026)

## Project Overview

This project analyzes Microsoft's financial performance over five fiscal years, from 2022 to 2026, using Python.

The objective is to evaluate revenue growth, profitability, asset efficiency, and financial structure through financial calculations and visual comparisons.

## Objectives

- Analyze Microsoft's financial performance over time.
- Calculate financial growth rates and key financial ratios.
- Compare annual results.
- Visualize financial trends using charts.
- Identify major financial strengths and trends.

## Dataset

The dataset contains five fiscal years of Microsoft financial information.

Key indicators include:
- Revenue
- Operating Income
- Net Income
- Total Assets
- Total Liabilities
- Total Equity
- Operating Cash Flow
- Capital Expenditure
- Total Debt

All financial values are expressed in USD millions.

## Financial Analysis

The project includes:

- Revenue Growth
- Operating Income Growth
- Net Income Growth
- Operating Margin
- Net Margin
- Return on Assets (ROA)
- Debt Ratio

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab
- GitHub

## Key Findings

Between 2022 and 2026:

- Revenue increased by 67.37%.
- Operating Income increased by 86.17%.
- Net Income increased by 83.88%.
- Operating Margin improved from 42.06% to 46.78%.
- Net Margin improved from 36.69% to 40.31%.
- Debt Ratio decreased from 54.35% to 41.67%.
